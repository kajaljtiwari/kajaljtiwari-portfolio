# Kajal Tiwari — Developer Portfolio

General-purpose portfolio for software development, full-stack, Python, backend, frontend and AI-related internship/job applications.

## Stack
- React + Vite
- Bootstrap
- React Icons
- Custom responsive CSS

## Before publishing
1. Replace the placeholder GitHub repository URLs in `src/main.jsx` with each project's actual repository URL.
2. Add the live Student Management System URL in the `demo` field for that project.
3. Add project screenshots to the project cards when ready.
4. The resume PDF is already included at `public/Kajal-Tiwari-Resume.pdf`.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
